# 单图示例

`mitosis.tif` 是 512 × 512 的公开细胞显微图，来自 scikit-image 的 `human_mitosis` 示例，图像权利人 David Root 以 CC0 发布。在这里用于验证单页 TIFF 的读取和推理。下载后的 SHA-256 与 scikit-image v0.22.0 数据注册表一致。

```text
2751ba667c4067c5d30817cff004aa06f6f6287f1cdbb5b8c9c6a500308cb456
```

[数据说明与采集文献](https://scikit-image.org/docs/0.22.x/api/skimage.data.html#skimage.data.human_mitosis) · [固定版本的原始 TIFF](https://gitlab.com/scikit-image/data/-/raw/2cdc5ce89b334d28f06a58c9f0ca21aa6992a5ba/AS_09125_050116030001_D03f00d0.tif) · [scikit-image 校验值](https://github.com/scikit-image/scikit-image/blob/v0.22.0/skimage/data/_registry.py)

[查看这张图的实际检测报告](mitosis-report.json)。模型识别并复核了四条观察，均被评为对来源判断呈中性，最后给出“证据不足”。这张示例的来源可由公开数据记录核实。
